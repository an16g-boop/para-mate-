# Página para descargar un video

## Preparar el video

1. Deja el archivo `WhatsApp Video 2026-11-16 at 1.23.26 PM.mp4` junto a `index.html`.
2. Si reemplazas el video, actualiza el nombre del archivo en los elementos `<source>` y `<a>` de `index.html`.
3. Abre `index.html` en un navegador para probar la página.

No se necesita instalar ningún programa para esta página. El video debe estar en formato MP4 para que sea compatible con la mayoría de teléfonos y computadoras.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube `index.html` y `WhatsApp Video 2026-11-16 at 1.23.26 PM.mp4` (puedes subir también este archivo).
2. En el repositorio, ve a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**; selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. Cuando termine la publicación, GitHub mostrará la dirección de la página en esa misma sección. Comparte esa dirección para que otras personas puedan abrir la página y descargar el video.

GitHub limita los archivos normales de un repositorio a 100 MB. Si el video supera ese tamaño, súbelo a una plataforma de archivos o a una publicación de GitHub Releases y actualiza las rutas del video en `index.html`.
